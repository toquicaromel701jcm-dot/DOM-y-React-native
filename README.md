# DOM y React Native – Contador de Likes

Proyecto académico del SENA: **De la Web al Móvil: Creando tu primer Contador de clics**.

## Estructura
- `web/`: versión web con HTML, CSS y JavaScript.
- `movil/`: versión móvil con React Native y Expo.
- `documentacion/`: bitácora y cuadro comparativo.

## Aplicación web
Abre `web/index.html` en un navegador. No requiere instalación.

## Aplicación móvil
Requiere Node.js y Expo:
```bash
cd movil
npm install
npx expo start
```
Escanea el QR con Expo Go. Si la versión de Expo Go de tu teléfono no es compatible con el SDK instalado, utiliza una versión de Expo compatible indicada por el propio instalador.

## Funcionalidades
- Sumar likes.
- Restar likes sin bajar de cero.
- Reiniciar contador.
- Guardar la hora de cada interacción en una tabla.
- Cambiar el color del contador cuando supera 10 likes.
